# mujocolab/mjlab

- **URL:** https://github.com/mujocolab/mjlab  
- **Docs:** https://mujocolab.github.io/mjlab/  
- **License:** see upstream

Isaac Lab–style manager API on MuJoCo Warp. Tasks include
`Mjlab-Velocity-Flat-Unitree-G1`, rough velocity, and
`Mjlab-Tracking-Flat-Unitree-G1` (BeyondMimic-style motion).

**Our use:** compile targets for `g1-walk`, `g1-walk-rough`, `g1-track`.
Prefer when operator has mjlab CLI; Playground remains the proven live path.
