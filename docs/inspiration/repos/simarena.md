# SimArena (CodecFlow)

- **Site:** https://simarena.ai/  
- **Docs:** https://docs.codecflow.ai/simarena/  

Browser drag-and-drop scenes, WASM physics, LeRobot export, MuJoCo/mjlab/Isaac
scene export, Fabric cloud train (roadmap/paid).

**Our use:** competitor to watch for UX patterns (scene gallery, export
dropdown). We do **not** build WASM physics — we stay recipe → train → video
over real engines. If users need a scene editor, export/import MJCF later.
