# DeepMimic (Peng et al., 2018)

- **PDF:** https://xbpeng.github.io/projects/DeepMimic/2018_TOG_DeepMimic.pdf  
- **Project:** https://xbpeng.github.io/projects/DeepMimic/  

Example-guided deep RL for physics characters: imitation reward +
reference-state initialization + early termination unlock dynamic skills.

**Takeaway for us:** motion imitation is a first-class humanoid path
alongside joystick RL. Informs why Tracking recipes matter after walk.
