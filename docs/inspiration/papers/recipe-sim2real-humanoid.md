# Sim-to-Real RL for Vision-Based Dexterous Manipulation on Humanoids

- **arXiv:** https://arxiv.org/abs/2502.20396  
- **Also:** RECIPE project materials  

Practical sim-to-real recipe for vision bimanual humanoid manipulation:
real-to-sim tuning, contact/object-goal rewards, policy distillation,
hybrid object representation.

**Takeaway for us:** grasp/dexterity is a later horizon. Keep Phase 4
loco + simple pickplace before vision-dexterous claims.
